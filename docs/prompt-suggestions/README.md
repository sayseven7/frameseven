# Prompt Suggestions

Ready-to-use mission prompts you can paste into your own AI agents to drive
FrameSeven-based offensive web pentests. Each file is a starting point — adapt
the target, scope, and depth to your engagement.

> Only use these against systems you own or have explicit permission to test.

- [Mission prompt](mission-prompt.md) — concise mission-style prompt covering
  recon, detection, and deep exploitation.
- [Full stack pentest](full-stack-pentest.md) — red-team prompt for a full-stack
  web pentest, from recon through post-exploitation.
- [Full stack pentest v2](full-stack-pentest-v2.md) — updated version with an
  explicit MCP skill/resource loading phase.
